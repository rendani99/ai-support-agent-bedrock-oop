# Engineering Reflection: AI Customer Support Agent Architecture

## Architectural & Design Decisions
In designing this e-commerce customer support agent, the central architecture decision was decoupling computational and operational responsibilities using the Model Context Protocol (MCP) via the Amazon Bedrock AgentCore Gateway alongside the AgentCore Code Interpreter. Rather than delegating discount arithmetic or points redemptions to LLM text generation—which is fundamentally vulnerable to token extrapolation errors and rounding inconsistencies—we routed loyalty tier calculations to the sandboxed Python code interpreter tool (`calculate_loyalty_discount`). This guarantees mathematical determinism for financial totals while freeing the foundational model (`amazon.nova-2-lite-v1:0`) to focus on conversational intent, sentiment recognition, and multi-turn conversational coordination.

## Concrete Challenge & Resolution
A notable challenge arose during the integration of cross-session persistence with the `MemoryHook`. The AgentCore Memory service operates asynchronously when extracting semantic facts (`customer_facts`) and user behavioral preferences (`customer_preferences`). In multi-session testing, invoking session B immediately after session A resulted in memory cache misses because the background semantic extraction pipeline requires a propagation window. We resolved this by standardizing the `MemoryHook.register_hooks` implementation to query both current strategy namespace templates dynamically via `get_namespaces()` and introducing a resilient fallback schema. In deployment testing, adding an ingestion settlement window between distinct session invocations ensured that facts like customer names and concise phrasing preferences were consistently retrieved and prepended to the prompt context.

## Production Considerations: Security, Cost & Observability
In an enterprise production deployment, two non-negotiable factors are security and cost governance. While the development setup utilizes a `NONE` authorizer on the AgentCore Gateway for rapid sandbox testing, a live implementation must enforce mutual TLS (mTLS) or IAM SIGv4 authentication on all Gateway endpoints to eliminate unauthorized invocation vectors. From a financial and scalability perspective, routing frequent, repetitive queries to a cached Bedrock Knowledge Base vector index prevents unbounded context-window inflation. Furthermore, integrating CloudWatch Logs and AWS X-Ray tracing across every Gateway target and Lambda function (`order_tracker` and `refund_processor`) provides end-to-end request latency visibility and auditing for audit-compliant customer support workflows.
